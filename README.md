# computils.js

Browser-first low-level programming tools in plain JavaScript.

This library or websites built upon this library does not replace the official NVIDIA CUDA Toolkit, Vulkan Toolkit, AMD HIP Toolkit, AMD ROCm Toolkit (THEROCK), Intel Graphics Compiler, Intel oneAPI Toolkit, Microsoft Visual C++, Apple Xcode, the LLVM/Clang toolchain and other official tools in certain situations.

## Requirements

- A modern browser with ES6/ES7 support, or specifically:
  - Chrome 52.0.x.xxxx and above
  - Firefox 55.0.xxx and above
  - Microsoft Edge 14.0 and above
  - Every modern Microsoft Edge version (based on Chromium)
  - Mac Safari 10.1 and above
  - Opera 39.0 and above
  - The web browser on iOS 10.3 and above
  - The web browser on Android 5.0 and above

**WE DO NOT SUPPORT INTERNET EXPLORER**.
