# Unofficial MessagePack documentation

MessagePack is a light, compact, fast and self-documenting binary serialization format implemented by and used in many desktop, mobile, server and embedded applications. It is intended to replace JSON in applications where text-based serialization formats (such as JSON, XML and YAML) are infeasible, or in extremely high performance or latency-sensitive applications. More information can be found at [msgpack.org](https://msgpack.org).
